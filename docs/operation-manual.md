# 運用マニュアル（初心者向け）

## 1. PDFを追加する

実文書は公開リポジトリへ置かず、ローカルの取り込み用フォルダに保存します。ファイル名と文書IDを決め、取り込みスクリプトの入力先を確認します。

## 2. チャンキングとEmbedding

`services/ingest` の依存関係をインストールし、`.env.example`をコピーして環境変数を設定します。APIキーはファイルへ直書きせず、環境変数で管理します。取り込みスクリプトを実行すると、PDF本文を小さなチャンクへ分割し、Gemini Embeddingでベクトル化します。

## 3. Workerへ登録する

Cloudflare Workerをローカルまたはデプロイ済みURLで起動し、登録APIへチャンク、ベクトル、メタデータを送ります。正常時はVectorizeとD1の両方に保存されたことを確認します。

## 4. 質問を確認する

UIまたは質問APIから、出典が表示される質問と「記載なし」となる質問を試します。回答だけでなく、出典文書と該当セクションも確認します。

## 5. エラー時の切り分け

1. Worker URLとHTTPステータスを確認する。
2. 環境変数名の誤り、未設定、余計な空白を確認する。
3. D1のマイグレーションとVectorizeのインデックス名を確認する。
4. Gemini APIの利用制限・モデル名・APIキーの有効性を確認する。
5. ブラウザからのエラーならCORS設定とPagesの環境変数を確認する。

秘密情報はログや質問CSVに出力しないでください。
